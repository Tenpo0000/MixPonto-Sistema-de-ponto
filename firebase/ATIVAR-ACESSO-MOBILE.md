# Atualização do acesso móvel e das permissões

O guia atual é [MULTICONTAS.md](../MULTICONTAS.md). Ele descreve a versão 1.3, a publicação única das regras e a concessão automática de acesso pelo painel web.

Não é necessário cadastrar o UID de cada convidado em `titularesAutorizados`. Os administradores existentes permanecem identificados nessa lista; os demais acessos são gerenciados em **Configurações → Usuários**.

Publique o conteúdo completo de `database.rules.json` desta pasta após guardar uma cópia das regras anteriores. A publicação não foi executada pelas ferramentas.
